VULNERABILITIES DISCOVERED & REMEDIATED
================================================================================
1. [HIGH] Insecure Direct Object Reference (IDOR) in Provider Service:
   - File: backend/routes/providers.py & backend/services/provider_service.py
   - Defect: update_provider and delete_provider allowed cross-tenant trainer mutations.
   - Fix: Added tenant_id scoping to SQL WHERE clauses.
2. [HIGH] Waitlist Cross-Tenant Mutation & Cancellation Vulnerability:
   - File: backend/services/waitlist_service.py & backend/routes/waitlist.py
   - Defect: promote_to_appointment and cancel_waitlist_entry queried WaitlistEntry by id only.
   - Fix: Added tenant_id scoping to WaitlistEntry queries.
3. [MEDIUM] Parameter Propagation Bug in Appointment Tooling:
   - File: backend/tools/platform.py
   - Defect: _reschedule_appointment and _cancel_appointment raised NameError on is_test.
   - Fix: Added is_test: bool parameter propagation.
